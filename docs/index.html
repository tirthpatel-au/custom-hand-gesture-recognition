How to test

  • Show a full open hand for Open Palm.
  • Close your hand into a fist for Fist.
  • Raise index and middle fingers for Peace.
  • Raise only your thumb for Thumbs Up.

Notes

  • The demo runs fully in the browser after loading the MediaPipe model.
  • Results are heuristic-based, so unusual angles can still confuse the label.
  • Better lighting and a clear hand silhouette improve accuracy.
